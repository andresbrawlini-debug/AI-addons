# Observador (The Observer)

**Minecraft Bedrock Edition** atmospheric behavior pack using the **Script API**.

The world quietly watches how you play. Sometimes it reacts — short messages, subtle sounds, light status effects. There is **no menu**, **no tutorial**, and **no published rule list**.

## Platform

| | |
|--|--|
| **Edition** | Minecraft **Bedrock** only (not Java) |
| **Minimum version** | **1.21.0+** |
| **Type** | Behavior pack (Script API) |

## Required setup

You **must** enable both:

1. This **behavior pack** on the world  
2. **Beta APIs** under **Experiments**

Without Beta APIs, the script does not run.

## Install

1. Import the `.mcpack`
2. World → Behavior packs → enable **Observador**
3. Experiments → **Beta APIs ON**
4. Play (Survival recommended)
